# store-movil

Aplicación **móvil** de FashionStore — Plataforma Inteligente de Comercio Electrónico.
Examen 1 · Sistemas II · S2-2026 · Grupo 44 · UAGRM.

## Stack

- Flutter 3.35 + Dart 3.9
- Plataformas: Android, iOS
- Realidad Aumentada para el vestidor virtual (CU20) — tecnología a definir (ARCore / plugin AR)
- Consume la API REST de `store-backend`

## Puesta en marcha

```bash
flutter pub get
flutter run
```

## Repositorios del proyecto

- `store-backend` — API REST (FastAPI)
- `store-frontend` — aplicación web (Angular)
- `store-movil` — este repo
